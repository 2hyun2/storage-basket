# 공간 입력·수정 공통 규칙

우리집 공간록에서 공간, 벽, 창문, 3D 배치 편집에 공통으로 적용하는 기준이다.

## 단위와 좌표

- 모든 실제 치수는 정수 `cm`로 저장한다.
- 사용자 화면의 평면 기준은 다음과 같다.

```text
X: 왼쪽 ↔ 오른쪽
Y: 위쪽 ↔ 아래쪽
Z: 바닥 ↔ 위쪽 (바닥에서의 높이)
```

- Three.js 내부 축 변환은 UI와 분리한다. 사용자는 항상 위 규칙만 본다.
- 기본 단층 공간은 `Z 좌표 = 0`이다.

## 부모 경계

- 자식 공간은 부모 경계에 정확히 맞닿을 수 있다. 별도의 1cm 여백은 두지 않는다.
- 자식 공간의 최대 크기는 부모의 해당 치수와 같다.
- 시작 좌표의 실제 최대값은 자식 크기까지 반영한다.

```text
X 최대 = 부모 가로 - 자식 가로
Y 최대 = 부모 세로 - 자식 세로
Z 최대 = 부모 높이 - 자식 높이
```

- 같은 부모 장면에 보이는 형제 공간·구조물은 평면 X/Y 영역이 겹칠 수 없다. 복층 Z값이 다르더라도 평면도에서 혼동되지 않도록 같은 바닥 면적을 함께 쓰지 않는다.
- 부모 장면의 벽·창문도 평면 배치에서는 공간을 차지하는 장애물이다. 같은 단계의 공간과 함께 표시하고, 겹치는 위치에는 저장할 수 없다.
- 자리 정하기 화면은 부모 벽까지의 좌·우·위·아래 거리와 형제 공간·구조물을 제외한 X/Y 가능 구간을 함께 표시한다. 형제 때문에 가능 구간이 여러 개로 나뉠 수 있으므로, 단일 최대값만으로 판단하지 않는다.

## 일반 공간 입력

일반 공간 등록·수정은 평면 설계가 기본이다.

```text
[좌표 X] [좌표 Y]

[가로 X] [세로 Y]
```

- 드래그는 1차 배치이다. 시작점과 끝점은 10cm 격자에 맞추고 X/Y, 가로/세로를 만든다. 클릭만 했을 때도 최소 10cm 한 칸으로 만든다.
- 숫자 입력은 2차 정밀 보정이다. 1cm 단위로 수정할 수 있다.
- 예상 격자는 반드시 부모 공간의 실제 가로 × 세로 비율과 최대 cm 범위를 사용한다.
- 텍스트 등록 공간은 부모 장면의 `미배치 공간`으로 남고, `3D 그리기`로 배치 편집을 시작한다.

## 높이 입력

- 공간 배치 저장은 `space_placements` 한 번만 요청한다. 내부 장면 생성과 치수 동기화는 `space_placements_sync_dimensions` DB 트리거가 담당한다.
- 상세 화면 진입 시 치수를 자동 저장하지 않는다. 저장 성공 후 Query를 재조회하며 DB의 장면·배치값을 그대로 사용한다.
- 이 흐름은 `202610300002_sync_space_dimensions.sql` 적용이 전제다. 최상위 집 크기는 별도의 사용자 입력이므로 직접 저장한다.

- 공간·벽·창문의 생성·수정에서 두 높이 입력을 항상 같은 순서로 보여 준다.

```text
[바닥에서의 높이] [공간 자체의 높이]
```

- 바닥에서의 높이는 시작 높이이며, 바닥에 놓으면 0cm이다.
- 공간 자체의 높이는 공간 또는 구조물의 아래부터 위까지 크기이다.
- 두 값의 합은 담고 있는 공간의 높이를 넘을 수 없다. 각 입력의 최대값은 다른 값을 차감하여 표시한다.
- UI의 바닥에서의 높이는 저장 시 렌더러의 `y_cm`으로 변환한다. 모든 값은 cm이다.
- 층 추가는 별도 기능이며 이 입력을 층수나 복층 여부로 부르지 않는다.

## 구조물

- 벽은 모델하우스처럼 사용자가 직접 배치하는 건축 요소다. 공간 경계는 격자와 배치 제한으로만 표현하며, 자동으로 벽을 렌더링하지 않는다.
- 외곽 벽과 내부 칸막이 모두 사용자가 필요한 위치에 추가·수정한다.
- 창문은 벽의 자식이 아니라 별개의 건축 영역이다. 통창도 하나의 창 영역으로 표현한다.
- 문 타입은 만들지 않는다. 통과 가능한 곳은 벽 구간을 비워 둔 `개구부`로 렌더링하며, 별도 물건이나 트리 노드가 아니다.
- 벽·창문에는 물건을 배치하거나 보관 위치로 연결하지 않는다.
- 벽·창문을 생성하거나 수정할 때는 언제나 **부모 기준 3D 장면**을 기본으로 렌더링한다. 장면에는 기존 공간, 기존 구조물, 격자, 부모 경계가 함께 보여야 한다.
- 빈 숫자 입력 화면만으로 구조물을 생성하지 않는다. 드래그로 1차 위치·영역을 정하고, 수치 입력으로 2차 보정한다.

## 저장 전 검증 순서

```text
정수 cm인가?
→ 크기가 1cm 이상인가?
→ 부모 경계 안에 들어오는가?
→ 형제 공간 또는 구조물과 충돌하지 않는가?
→ 창 영역이 부모 경계 안에 들어오는가?
→ 저장
```

## 화면 원칙

- Home 크기가 설정되기 전에는 공간 등록·텍스트 트리·3D 장면을 보여주지 않는다.
- Home 크기 설정 후에만 최상위 공간을 만들 수 있다.
- 3D 장면은 항상 상단 시점으로 시작한다.
- 격자는 장면보다 크게 렌더링하지 않는다.
- 텍스트 트리와 3D는 동일한 `location_id`를 사용한다.
- 모든 생성·수정 화면은 현재 적용 대상의 3D 장면을 기본 컨텍스트로 제공한다.
