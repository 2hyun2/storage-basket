# 계정별 3D 시점

- 컴포넌트: `components/space/saved-view-controls.tsx`.
- 로그인 후 집 전체 배치도·홈의 배치도·공간 내부 탐색 화면이 같은 선호 시점을 사용한다.
- 인트로 데모, 공간 배치 편집 미리보기, 구조물 편집 화면은 제외한다.
- 저장 키: `storage-basket:space-view:v1:<userId>`. 비밀번호·토큰을 저장하지 않는다.
- 카메라와 보기 중심의 상대 위치를 공간의 가로·세로 중 큰 값으로 나누어 저장한다. 다른 크기의 공간에서 비율을 복원한다.
- 현재 시점 저장: 카메라 상태를 저장. 저장한 시점으로 복귀: 저장 상태를 재적용. 기본 시점 초기화: 계정의 저장값을 제거하고 기본 카메라·중심으로 복귀.
- 계정 변경 시 새 계정 설정을 읽는다. 다른 계정 저장값은 사용하지 않는다.
- 저장소 오류·잘못된 JSON은 기본 시점으로 표시한다. 버튼에서 오류가 발생하면 사용자에게 안내한다.
- 동일 브라우저의 로컬 설정이며 서버 동기화하지 않는다.

## 브라우저 QA

1. 계정 A로 회전·확대 후 저장. 새로고침과 다른 크기 공간 진입 시 각도·비율 확인.
2. 둘러본 뒤 복귀 버튼으로 저장한 시점 확인.
3. 초기화 후 기본 시점 및 새로고침 시 기본 유지 확인.
4. 계정 B는 A의 저장값 없이 기본 시점 시작. B 저장 후 A 재로그인 시 A 설정 복원 확인.
5. 저장소 차단 상태에서 오류 안내 확인.
6. 인트로·생성·수정 화면에 저장 버튼이 없는지 확인.

타입·린트 검사와 실제 브라우저 조작 검증은 구분한다. 위 실사용 시나리오는 별도 확인이 필요하다.
