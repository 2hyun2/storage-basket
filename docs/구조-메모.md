# 수납바구니 구조 메모

## 현재 데이터 흐름

- `data/`의 더미 데이터를 `useInventory`가 브라우저 메모리 state로 관리한다. 새로고침하면 생성한 데이터는 사라진다.
- `useAppStore`는 선택한 위치·물건, 검색어, 정렬, 모달 열림 여부처럼 화면 UI 상태만 관리한다.
- `useVisibleItems`가 위치 선택(하위 위치 포함) → 검색 → 정렬 순서로 목록을 계산한다.
- `App`은 위 결과를 레이아웃과 모달 컴포넌트에 연결한다.

## 파일별 책임

| 파일 | 책임 |
| --- | --- |
| `App.jsx` | 화면 조립과 선택된 데이터 조회 |
| `hooks/useInventory.js` | 물건·위치 임시 데이터와 생성 |
| `hooks/useAppUi.js` | Zustand UI 상태의 앱용 인터페이스 |
| `hooks/useVisibleItems.js` | 목록 필터·검색·정렬 규칙 |
| `stores/useAppStore.js` | 공유 화면 UI 상태와 상태 변경 함수 |

## 다음 변경 시 기준

- API 연결 전까지 데이터 변경은 `useInventory`에 둔다.
- 모달 열기, 선택, 검색처럼 화면 표현을 위한 값은 Zustand에 둔다.
- 목록 표시 규칙은 컴포넌트 JSX 안이 아니라 `useVisibleItems`에 둔다.
