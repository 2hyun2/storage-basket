# 수납바구니 작업 목록

## 서비스 목표

집 안 물건의 보관 위치를 텍스트로 기록하고 빠르게 검색한다. 원하는 사용자는 같은 위치 트리를 직육면체 기반 3D 공간으로 꾸밀 수 있다.

## 핵심 원칙

- 위치는 `id`와 `parentId`로 연결되는 깊이 제한형 트리다.
- 사용자에게는 위치 이름을 자유롭게 입력받는다.
- 물건은 위치와 수량을 포함한 독립 기록으로 관리한다.
- 같은 물건이 여러 곳에 있으면 각각 별도 물건 기록을 만들고, 제목 검색으로 함께 찾는다.
- 텍스트 위치 데이터가 원본이며, 3D 데이터는 선택적인 시각화다.
- 3D 노드는 부모 기준의 로컬 좌표를 사용하며, 길이 단위는 미터(m)로 통일한다.
- 3D의 모든 형태는 직육면체로 시작한다.

## 기술 방향

- 프론트엔드: React + Vite
- 스타일: Tailwind CSS
- 서버 상태: TanStack Query
- 화면 상태: Zustand
- 3D: React Three Fiber + Drei
- 백엔드: Node.js + Express
- 데이터베이스·인증: Supabase / PostgreSQL
- 로컬 실행 환경: Docker + Docker Compose
