## 운영자와 함께 확정할 내용

### 2026-10-30 대시보드 확인 결과

- Vercel `storage-basket` / Settings / Functions: Washington, D.C., USA (East), us-east-1, iad1 체크 상태 확인. Hobby 플랜, Fluid Compute 활성. 설정은 변경하지 않았다.
- Vercel Logs의 기간 선택: 무료로 1시간 조회, 더 긴 기간은 업그레이드 항목으로 표시됨. 조회 가능 기간을 전체 로그·백업의 실제 파기 기간으로 단정하지 않는다.
- Supabase: 기존 열린 설정 탭을 읽으려 했으나 저장된 브라우저 권한이 원본 사이트 접근을 거부했다. 리전·로그·백업 설정은 미확인. 우회 접근하지 않았다.
- 이후 사용자 제공 Infrastructure 화면에서 Primary Database: Southeast Asia (Singapore), ap-southeast-1, Nano를 확인했다. 기본 DB 지역만 확인되었으며 로그·백업·지원 처리 지역과 보관 기간은 미확인이다.

1. Supabase 기본 DB 리전은 싱가포르로 확인 완료. 로그·지원 등 기타 처리 지역은 추가 확인한다.
2. Vercel 서버 지역 및 로그 처리·보관 설정 확인. 서버 리전 하나만으로 전체 처리 국가를 단정하지 않는다.
3. Supabase·Vercel 계약/DPA·수탁자 및 하위처리업체를 확인해 위탁·국외 처리의 수령자, 국가, 항목, 목적, 시점·방법, 보유기간, 근거 및 거부 절차를 정한다.
4. 인증·오류·접속 로그 및 백업 보관 기간 확인.
5. 계정 삭제 시 소유 공동체 승계, 공유 기록 유지·익명화, 활동 기록 사용자 식별자, Auth·profiles 삭제 제약을 검토하고 실제 삭제 절차를 구현·검증한다.
6. 동의 또는 계약 이행 등 항목별 처리 근거 검토. 별도 동의가 필요한 처리에는 서버 검증 및 동의 이력도 설계한다.
7. 미성년자 가입 운영 범위 및 필요한 연령 확인·법정대리인 동의 절차 검토.
8. 문의 이메일을 실제로 확인하고 열람·정정·삭제·처리정지 요청을 처리하는 담당 운영 절차를 마련한다.
9. 개인정보처리방침의 시행일과 개정 이력을 확정하고 초안 표시를 제거한다.
